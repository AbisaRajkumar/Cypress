Package Overview:
-----------------
This ZIP archive contains the final deliverables for Sprint 3 of the CPS406 project "Cypress". The Cypress app enables residents to report issues via a map or phone, and allows city officials to update and manage reported issues. Key features include role-based login, issue reporting with categories and descriptions, zone-specific contact lookup, and admin tools for marking issues as solved.

Instructions:
-------------
1. Run `main.py` to launch the application.
2. Use the signup screen to create a resident or city official account.
3. Residents can report issues via the map or call lookup.
4. City officials can update the status of reported issues.
